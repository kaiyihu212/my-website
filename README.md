# LUNAMOON · 水晶饰品与冥想生活

简体中文水晶品牌网站，基于 Next.js App Router、React、TypeScript、Tailwind CSS 4 和 Lucide Icons。视觉以米白、暖棕、天然材质与写实场景为主，包含可暂停的三场景轮播、滚动上移浮现、手链、水晶球、晶簇摆件、文化内容与出生时间排盘。

这是购买流程演示，不含真实支付、服务器订单或客户资料采集。GitHub 仓库设置中的网站地址为 `https://my-website-tawny-chi.vercel.app`；本环境无法直接访问该域名，也没有读取 Vercel 部署状态的权限，更新是否已上线应以 Vercel 的部署结果为准。

## 开发与验证

推荐 Node.js 22 或 24。

```sh
npm ci
npm run dev
```

开发服务监听 3000 端口。通过本地终端显示的地址，或支持端口预览的开发平台访问。

```sh
npm run typecheck
npm run build
npm run start
```

浏览器测试使用独立的 3100 端口，避免误测仍在运行的旧开发服务：

```sh
# 本云环境使用已有 Chromium，无需额外下载
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test

# 其他机器首次安装测试浏览器
npx playwright install chromium
npm test
```

测试涵盖桌面和手机的中文页面、横向溢出、购物袋持久化、分类、排序、尺寸、模拟结账、订阅不提交、轮播自动切换与暂停、减少动态效果、滚动浮现、历法与时区边界、排盘与出生信息不持久化。桌面项目中的手机导航测试按设计跳过，在手机项目执行。

## 静态托管

```sh
npm run build:static
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:static
npm run preview:static
```

`.next-static/` 包含 24 个应用页面及本地图片、脚本和样式，可以上传到以域名根路径提供服务的静态托管平台。预览命令只启动本机 3100 端口，不会公开发布。需要更改验证端口时可设置 `STATIC_PREVIEW_PORT`。

静态构建会更新 `.next` 缓存；之后如需 `npm run start`，请先重新执行普通 `npm run build`。

Vercel 可以导入此 GitHub 仓库，采用 Next.js 默认构建设置。Netlify 可以使用仓库中的 `netlify.toml` 构建并发布 `.next-static`。推送后是否自动部署、部署是否成功，取决于托管平台的仓库连接和项目设置。

## 页面与购物

- `/`：三场景轮播、三类商品入口、心意选择、精选商品、脉轮、生活仪式、八字入口、手记、订阅
- `/shop`：九款演示商品，按手链、水晶球、摆件、心意筛选，支持中文搜索与价格排序
- `/product/[id]`：商品详情、手围或摆件规格、数量、护理和相关推荐
- `/intentions`、`/chakras`：六种心意与传统七脉轮文化
- `/bazi`：公历出生日期、时间、出生地时区 → 四柱 → 五行色彩与商品灵感
- `/journal`、`/journal/[id]`：五篇中文演示手记
- `/story`、`/faq`：品牌理念、护理、隐私与演示说明
- `/bag`、`/checkout`：本地购物袋与模拟结账

购物袋仅存于当前浏览器 `localStorage` 的 `lunamoon-bag` 键。无银行卡或地址表单、真实扣款、发货或后台订单。邮件订阅不保存、不上传邮箱。

## 品牌与图片配置

- `lib/brand.json`：品牌名、副标题、标语和货币。`npm run dev`、`npm run build` 和静态构建会从这里同步导出 SVG 的品牌字标，也可单独运行 `npm run logos`。
- `lib/data.ts`：产品名称、材质、价格、规格、库存、类别、图片位置与内容文章。
- `components/HeroCarousel.tsx`：三种场景和文案，7 秒自动切换，可暂停、手动切换、键盘左右键与触屏横滑；鼠标停留、键盘进入、离开视野及页面后台时暂停；系统减少动态效果时禁用自动播放。
- `components/ScrollReveal.tsx`：文字与图片分组上移浮现。内容默认可见，浏览器支持且允许动效时才渐进增强；减少动态效果和键盘焦点均不隐藏内容。
- `app/globals.css`：暖色静奢视觉、字体栈、响应式与动效。中文使用系统宋体/黑体回退，不请求外部中文字体。
- `public/photos/`：参考自然珠宝摄影方向生成的 AI 示意：低饱和、柔光、肌肤与亚麻细节，并穿插灰绿水纹、矿石与贝壳。三张 `*-editorial.webp` 首页场景为独立图片，`catalogue-editorial.webp` 为九种商品的摄影风格示意合集，通过 CSS 按格显示，`photoIndex` 决定对应图格；`water-study.webp` 与 `shell-study.webp` 为自然细节编辑图。新文件名避免浏览器沿用旧图。
- `public/logos/`、`public/favicon.svg`：月牙、金色圆环、四角星、细线和圆点 SVG，包含主标志、横向与深浅版本。
- 早期 SVG 商品插图及首版 WebP 场景仍保留在仓库，当前商品和首页已切换到新的摄影方向。

AI 图片是场景与商品设计示意，**不是实物摄影或材质证明**。图片中饰件、木托和晶体形态均未经实物核实，正式销售前必须替换为有使用权且与实际商品一致的摄影。三款新增水晶球/摆件的 AUD 价格和规格也是演示数据。

## 八字体验的规则与边界

排盘引擎为 `lunar-typescript`（MIT），只有用户点击排盘时才按需加载。出生信息在浏览器内计算，不上传、不写入本地存储，刷新即清除。表单在客户端就绪前禁用，避免原生表单意外发送出生信息。

采用的规则明确展示在页面中：

1. 用户输入出生地的公历钟表时间，按 IANA 时区规则换算时间点，包括历史夏令时。
2. 统一转为北京时间 **UTC+8** 排盘，以立春换年、节气换月、午夜零点换日（库的 sect 2）；不校正经度与真太阳时，晚子时时柱遵循引擎规则。
3. 夏令时跳过的时刻会报错；回拨而重复的时刻要求用户主动选择较早或较晚的一次。
4. 仅按日干所属五行提供传统色彩联想与商品关联。不是喜用神分析，不以数量判断缺什么、补什么，不提供命运、治疗或改变运势的承诺。

不同时间校正规则与流派可能给出不同结果，临近节气、换日和时辰边界时尤其应留意。这里是文化与审美体验，不是专业命理服务。

## 正式营业前

九款商品的材质、价格、库存、尺寸及图像均待核实。礼盒分类保留诚实的未上架状态。没有虚构的评价、销量、认证或采购来源。

实际营业前需补充产品摄影和规格、经营主体与联系方式、配送退换、税费与隐私条款；确定正式域名后完善 canonical、站点地图及分享图。真实支付和服务器订单仅在单独授权后接入。
