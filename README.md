# LUNAMOON · 水晶饰品与冥想生活

面向简体中文用户的独立水晶珠宝品牌体验，基于 Next.js App Router、React、TypeScript、Tailwind CSS 4 和 Lucide Icons。尚未部署，不含真实支付、后台、订单服务或客户信息采集。

## 本地开发与预览

推荐 Node.js 22 或 24。

```sh
npm ci
npm run dev
```

浏览器访问终端显示的 3000 端口。云环境请使用平台提供的端口预览功能（如平台支持），或将仓库下载到本机运行；当前 onboarding 界面不提供对外网站预览链接。开发服务器监听 `0.0.0.0`，这不等于正式部署。

生产构建与本地启动：

```sh
npm run build
npm run start
```

## 页面

- `/`：品牌首页、六种心意、精选商品、七脉轮、生活仪式、手记与订阅演示
- `/shop`：分类、中文搜索、心意筛选和价格排序；礼盒为空状态，未虚构商品
- `/product/rose` 等六个详情页：尺寸、数量、护理、佩戴灵感和推荐
- `/intentions`：六种可交互的意向、正念建议和关联商品
- `/chakras`：七种传统脉轮象征及相关商品
- `/journal`、`/journal/[id]`：五篇完整中文演示文章
- `/story`：品牌理念与设计语言
- `/bag`、`/checkout`：本地购物袋和模拟结账
- `/faq`：护理、尺寸、演示、隐私及待制定的配送退换说明

## 配置与素材

- `lib/brand.json`：品牌名、副标题、标语和货币集中配置。`npm run dev` 与 `npm run build` 会自动同步导出 SVG 的品牌字标，也可执行 `npm run logos`。
- `lib/data.ts`：商品数据、价格、库存、尺寸、图片路径、心意、脉轮及文章。
- `app/globals.css`：品牌色、字体栈、响应式排版与组件样式。使用系统宋体/黑体优先的字体回退，不加载大体积中文网络字体，确保离线字体回退及首屏性能。
- `public/logos/`：参照提供图形重绘的月牙、圆环、四角星、细竖线与圆点 SVG；包含主 Logo、横向、独立图标及深浅版本。网站字标直接读取品牌配置；独立导出 SVG 的字标通过脚本从品牌配置自动同步。
- `public/favicon.svg`：独立图标。
- `public/hero.svg`、`public/products/*.svg`：本项目原创 SVG 示意，无第三方摄影授权依赖。页面明确标注非实物摄影；正式上线前应替换为有使用权且与实物相符的摄影。
- 首页生活静物和手记封面为 CSS 原创示意图形。

购物袋通过浏览器 `localStorage` 的 `lunamoon-bag` 键保存，仅保存在当前浏览器。清理站点数据即可移除。没有服务器订单写入；订阅不上传、不保存邮箱，结账不要求收货或支付信息。

## 独立托管网站包

```sh
npm run build:static
```

该命令输出 `.next-static/`，包含 20 个页面及全部本地图片、样式和脚本，可将其中的文件直接上传至以域名根路径提供服务的静态托管平台。购物袋和模拟结账仍可运行，无需 Node.js 后端。不要仅双击 HTML 文件预览，应使用 HTTP 服务或托管平台。

注意：Next.js 的静态导出也会更新 `.next` 构建缓存；如需重新运行 `npm run start`，应先运行普通的 `npm run build`。

当前尚未发布到公网。GitHub API 网络访问现已恢复，但当前 GitHub 连接访问 Pages 和 Actions 管理接口均返回 `Resource not accessible by integration (403)`，因此无法通过此连接直接配置 GitHub Pages。仓库保持私有。

### 使用托管平台生成访问网址

可在 Vercel 登录后选择导入 Git 仓库，授权访问 `kaiyihu212/my-website`，保持 Next.js 默认设置并部署。Vercel 根据实际部署结果分配访问域名。也可在 Netlify 导入该仓库，项目自带 `netlify.toml` 会构建并发布静态版本。平台可能需要登录、仓库授权或确认套餐；不要提供账号密码给聊天。

如果使用现成网站包，将包解压后把包含 `index.html` 的文件夹上传到支持手动部署的静态托管服务即可。所有上线版本仍为购买流程演示，不接真实支付。
